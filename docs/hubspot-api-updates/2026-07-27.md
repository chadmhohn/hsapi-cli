## Outcome

- Updated the catalog from 637 to 650 HTTP endpoints.
- Promoted three current Lists/Segments operations to typed commands, raising typed coverage from 315 to 318 commands.
- Made Agent CLI diagnostics build-aware and capability-aware because HubSpot changed the beta binary without changing version `0.10.0`.
- Expanded the non-mutating updater to use HubSpot's sitemap, recognize newly published path families, retain beta proposals, and classify validation POSTs as read-only candidates.

## Stable API Additions

| Family | Added catalog coverage | Auth and safety posture |
| --- | ---: | --- |
| Network origins | 2 GET endpoints | Public; `auth.required: false`; no credential may be attached. |
| App uninstall | 1 DELETE endpoint | Installed-account OAuth with `oauth`; destructive and `--yes` gated. |
| Public-app feature flags | 4 reads and 6 writes | Catalog-only developer app surface; developer API key per the current guide; writes remain `--yes` gated. |

Feature flag auth has a documented inconsistency: the current guide uses the developer account API key through `hapikey`, while generated OpenAPI security metadata names `developers-read` and `developers-write`. The catalog records both facts, selects the guide's developer-key mechanism, and keeps the family catalog-only pending confirmation before any typed promotion.

## Native Lists/Segments Parity

The newer Agent CLI exposes `segments`, but these operations have documented public Lists API equivalents. HSAPI therefore keeps them native and portal-aware:

- `hsapi lists members-add <listId> --record-ids ...`
- `hsapi lists members-remove <listId> --record-ids ...`
- `hsapi lists update-filters <listId> --filter-branch ...`

The first-party Agent CLI bridge remains limited to saved reports and saved CRM views, where equivalent public app endpoints are not documented.

HubSpot documents the Lists API scopes as alternatives: one of `cms.membership.access_groups.write`, `crm.lists.read`, or `crm.lists.write`. The catalog's flat `requiredScopes` array cannot express OR semantics, so these three commands keep that array empty and record the complete one-of rule in `scopeNotes` instead of incorrectly claiming that multiple scopes are jointly required.

## Reviewed Backlog

The stable Media Bridge family is real but specialized and has 29 wholly uncataloged routes in the audited OpenAPI snapshot. It should be handled as a separate tranche because it combines developer-account setup with installed-account OAuth scopes.

The `2026-09-beta` docs audit found 53 missing exact method/path pairs across Automation, Forecasts, Data Studio ingestion, Marketing AEO, Forms, Payment Links, Price Books, and IP-range webhook subscriptions. They were not bulk-imported: beta versioning, scopes, tier requirements, multipart bodies, and destructive operations need family-by-family review. The updater now discovers these families and will preserve beta candidates rather than suppressing them as GA duplicates.
